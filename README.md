# Sistema de Monitoramento de Rede (NetMonitor)

Aplicação desenvolvida para monitoramento e gestão de dispositivos de rede.

## 🚀 Funcionalidades
- Cadastro e listagem de ativos de rede (roteadores, switches, servidores).
- Teste de conectividade e status dos dispositivos.
- Automação e validação de código via CI/CD.

## 🛠️ Tecnologias Utilizadas
- Python 3
- Git & GitHub (GitHub Flow)
- GitHub Actions (CI)
